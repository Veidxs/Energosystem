# Симулятор енергосистеми України (ОЕС)

Інтерактивна веб-модель до шкільного проєкту з фізики (11 клас) на тему **«Побудова моделі енергосистеми України»**.

**Виконали учні 11 класу:** Швець Сергій, Артемчук Назар, Качуровська Даша.

## Структура проєкту
- `index.html` — адаптивна розмітка (ПК + телефон) із горизонтальною та вертикальною SVG-схемами кільцевої ЛЕП.
- `styles.css` — бежево-графітова палітра, анімація потоків струму та зручні сенсорні повзунки.
- `app.js` — фізико-математична модель (закон Джоуля–Ленца $P_{\text{втр}} = I^2R$, баланс потужності, частота 50 Гц та автоматика АЧР < 49,5 Гц, графіки Chart.js).

## Як завантажити на GitHub і відкрити за посиланням (GitHub Pages)
1. Створіть новий репозиторій на GitHub (наприклад, `ua-energy-grid-sim`).
2. Завантажте файли `index.html`, `styles.css`, `app.js`, `README.md` через кнопку **Add file → Upload files** або через консоль:
   ```bash
   git init
   git add .
   git commit -m "Add Ukraine energy grid simulator"
   git branch -M main
   git remote add origin https://github.com/<ваш-логін>/<ваш-репозиторій>.git
   git push -u origin main
   ```
3. У репозиторії відкрийте **Settings → Pages → Branch: `main` → Save**. За 1–2 хвилини симулятор відкриватиметься з будь-якого телефона чи шкільного комп'ютера за посиланням `https://<ваш-логін>.github.io/<ваш-репозиторій>/`.
